# MeteorStrike

This is the first game I made on my own during my Terminale Générale.

---

## 🎮 Controls

### Solo mode
- Move left: Q or Left Arrow
- Move right: D or Right Arrow

### Duo mode
- Player 1: Left / Right arrows
- Player 2: Q / D

---

## 🕹️ Game rules

### Solo mode
- Avoid meteors falling from the sky
- You have 3 lives per level
- Each level lasts 10 seconds
- Infinite levels (difficulty increases over time)

### Duo mode
- Same rules as Solo mode
- The winner is the last player alive
